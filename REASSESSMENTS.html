What this demonstration implements

A valid cache hit supplies an actual computed check result. A miss creates or joins a shared job. Delivered values remain in the case accumulator even if their cache entries are later evicted. Updates replace pending case generations while preserving their original deadlines. A case publishes only when all check versions match its current target.

At an equal timestamp, updates take effect before completions and publication. The no-cache baseline still shares overlapping jobs and preserves delivered values within a pending request. Full recomputation additionally disables that sharing and carry-over. Both baselines retain the same worker and version-safety rules.

All values and durations are synthetic. This engine models a finite worker pool and result-cache slots; connecting worker jobs to container startup and retention is a later step. The result-cache budget does not bound total host memory.
