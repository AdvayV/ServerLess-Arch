What the model does

Each cached score component includes the question's rubric version, submission version, and grader version. A correction invalidates only old components for that question. Correctly versioned components remain reusable.

FIFO serves older work first. Earliest-deadline-first serves the closest deadline first. Fair earliest-deadline adds per-student service accounting and waiting-age relief. The cache comparison uses least-recently-used versus a Greedy-Dual-style score that considers access frequency and recomputation cost.

Workers have fixed capacity, so jobs queue. A completed grade is published only if its rubric is still current. Synthetic results do not show learning outcomes or predict how a real university should allocate resources.
